# CellProfilerCustomModules
TremblayLab CellProfiler 4.2.8.x Custom Modules

A Guide on how to use the CellProfiler custom modules for hierarchical and k-means clustering 

	1. The input csv file to be used for the analysis 
The Example data frame, contains an example of a data frame that could be analyzed using the custom CellProfiler modules. The data frame should contain the following columns 
a) ObjectNumber - containing a number for each microglia within each image. 
b) FileName_Blind - containing a blinded ID for each image
c) Condition - containing information on the level of the categorical variable that will be used to make comparisons between groups. In this case, the cluster assignments of microglia derived from the ventral hippocampus will be compared with microglia derived from the medial prefrontal cortex. The Condition column is not automatically generated by the morphology pipeline used for detection of microglia morphology and should be added manually.

To ensure that the custom modules can be used as intended it is crucial to ensure the above mentioned columns are named exactly as described above. 

	2. The set-up 
The appropriate operating system should be selected and the command lines, as can be found in the publication document, should be copied and pasted into the terminal. Running these commands facilitates the download of the custom modules into CellProfiler. 

	3. Outlier detection 
The pipeline includes a module providing the detection of outlying values representing potential artefacts, that have been incorrectly labeled as microglia. The output generated by this module contains. 
a) scatterplot - displaying the distribution of the identified microglia, labeled as either inliers or outliers. 
b) csv file - containing information on the corresponding image and object number. 
For each of the identified outlier, the object that has been detected as a microglia, should be checked individually. 

	4. Hierarchical clustering for the ideal number of clusters to include 
A hierarchical clustering analysis leading to the generation of a histogram, which will guide the user in their selection of the number of clusters best representing the data. 

	3. The output provided by the CellProfiler modules
The output generated by the CellProfiler modules contains 
a) an output csv file - containing information on the cluster assignment for each microglia
b) scatter plot - displaying the distribution of the identified microglia, with each microglia possessing a colour corresponding to their cluster assignment 
c) barchart - displaying the abundance of the identified clusters in relation to the groups compared in the sample
