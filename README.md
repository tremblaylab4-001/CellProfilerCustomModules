# CellProfilerCustomModules
TremblayLab CellProfiler 4.2.8.x Custom Modules

A Guide on how to use the CellProfiler custom modules for hierarchical and k-means clustering 

# 1 The input csv file to be used for the analysis 

The Example data frame, contains a csv file that could be analyzed using the custom CellProfiler modules. Next to the measurements of microglia morphological features. The data frame must contain the following columns three columns. To ensure that the custom modules can be used as intended it is crucial to ensure the above mentioned columns are named exactly as described.
### a) ObjectNumber 
Containing a number for each microglia within each image.  
### b) FileName_Blind 
Containing a blinded ID for each image
### c) Condition 
Containing information on the level of the categorical variable that will be used to make comparisons between groups. In this case, the cluster assignments of microglia derived from the ventral hippocampus will be compared with microglia derived from the medial prefrontal cortex. The Condition column is not automatically generated by the morphology pipeline used for detection of microglia morphology and should be added manually.

# 2 The set-up 

The appropriate operating system should be selected and the command lines, as can be found in the publication document, should be copied and pasted into the terminal. Running these commands facilitates the download of the custom modules into CellProfiler. 

# 3 Outlier detection 

The pipeline includes a module providing the detection of outlying values representing potential artefacts, that have been incorrectly labeled as microglia. The output generated by this module contains. 
### a) scatterplot 
Displaying the distribution of the identified microglia, labeled as either inliers or outliers. 
### b) csv file 
Containing information on the corresponding image and object number. For each of the identified outlier, the object that has been detected as a microglia, should be checked individually. 

# 4 Hierarchical clustering for the ideal number of clusters to include 

A hierarchical clustering analysis leading to the generation of a histogram, which will guide the user in their selection of the number of clusters best representing the data. 

# 5 The output generated by the CellProfiler modules contains 
### a) an output csv file 
Containing information on the cluster assignment for each microglia
### b) scatter plot 
Displaying the distribution of the identified microglia, with each microglia possessing a colour corresponding to their cluster assignment 
### c) bar plot 
Displaying the abundance of the identified clusters in relation to the groups compared in the sample
